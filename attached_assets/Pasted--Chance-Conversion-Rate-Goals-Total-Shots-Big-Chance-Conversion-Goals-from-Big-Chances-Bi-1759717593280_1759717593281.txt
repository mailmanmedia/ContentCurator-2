• Chance Conversion Rate = Goals / Total Shots
• Big Chance Conversion = Goals from Big Chances / Big Chances
  (Big Chance defined as xG >= 0.35 per shot)

Calculation Example:
Liverpool over 10 matches:
- 18 goals scored
- 52 shots on target
- 22.4 xG
- 135 total shots
- 24 big chances, 11 scored

GE = (18 / 52) × (18 / 22.4)
GE = 0.346 × 0.804 = 0.278 (27.8% efficiency)

Chance Conversion = 18 / 135 = 13.3%
Big Chance Conversion = 11 / 24 = 45.8%

Interpretation:
• GE > 0.30: Elite finishing
• GE 0.25-0.30: Strong finishing
• GE 0.20-0.25: Average finishing
• GE < 0.20: Poor finishing

---

B4. DEFENSIVE SOLIDITY INDEX
Purpose: Measure defensive quality and chance prevention

Formula:
DSI = [1 - (GA / SOT_Against)] × (1 + Clean_Sheet_Rate) × Pressing_Factor

Where:
• GA = Goals Against
• SOT_Against = Shots on Target Against
• Clean_Sheet_Rate = Clean Sheets / Matches Played
• Pressing_Factor = PPDA_relative (Team PPDA / League Avg PPDA)
  - Lower PPDA = better pressing = higher factor
  - Factor = League_Avg / Team_PPDA

Additional Component - Shot Prevention:
DSI_Enhanced = DSI × (1 - xGA_per_match / League_Avg_xGA)

Calculation Example:
Liverpool over 10 matches:
- 8 goals conceded
- 28 shots on target against
- 4 clean sheets
- PPDA: 9.89 (League avg: 12.5)
- xGA: 11.2 (1.12 per match, league avg: 1.35)

Base calculation:
Shot_Stop_Rate = 1 - (8/28) = 1 - 0.286 = 0.714
Clean_Sheet_Multiplier = 1 + (4/10) = 1.4
Pressing_Factor = 12.5 / 9.89 = 1.264

DSI = 0.714 × 1.4 × 1.264 = 1.262

Enhanced with xGA:
xGA_Factor = 1 - (1.12 / 1.35) = 1 - 0.830 = 0.170
DSI_Enhanced = 1.262 × (1 + 0.170) = 1.476

Interpretation:
• DSI > 1.5: Elite defense
• DSI 1.2-1.5: Strong defense
• DSI 0.9-1.2: Average defense
• DSI < 0.9: Vulnerable defense

B5. HOME/AWAY PERFORMANCE DIFFERENTIAL
Purpose: Identify venue-specific strengths or weaknesses

Formula:
HAPD = (Home_PPG - Away_PPG) / League_Avg_HAPD

Where:
• PPG = Points Per Game
• League_Avg_HAPD typically ~0.3-0.5 points

Additional venue metrics:
• Home_GD_Advantage = (Home_GD/Home_Matches) - (Away_GD/Away_Matches)
• Home_xG_Swing = (Home_xG_Diff) - (Away_xG_Diff)
• Crowd_Impact_Factor = Home_Win% with >50k attendance vs <50k

Calculation Example:
Liverpool season to date:
- Home: 8 matches, 21 points (2.63 PPG), +14 GD
- Away: 7 matches, 14 points (2.00 PPG), +6 GD
- League average HAPD: 0.4

HAPD = (2.63 - 2.00) / 0.4 = 0.63 / 0.4 = 1.58

Home_GD_Advantage = (14/8) - (6/7) = 1.75 - 0.86 = +0.89 goals/match

Interpretation:
• HAPD > 1.5: Strong home advantage (using it well)
• HAPD 0.8-1.5: Normal home advantage
• HAPD 0.3-0.8: Weak home advantage
• HAPD < 0.3: No home advantage (concern)

C2. MOMENTUM SCORE

Where:

• Position_Pressure:

  - If mid-table (9-14): PP = 50
  - If relegation zone (15-20):
    PP = 30 + (Points_Above_18th × 2)

• Goal_Momentum = (Goals_Last_3 - Goals_Conceded_Last_3) × 5
  Capped at ±30

Calculation Example:
Liverpool current state:
- Form Index: 2.57/3.0 = 85.7
- 2 points behind leader: PP = 100 - (2 × 5) = 90
- Last 3 matches: 8 scored, 2 conceded: GM = (8-2) × 5 = 30

MS = (85.7 × 0.5) + (90 × 0.3) + (30 × 0.2)
MS = 42.85 + 27 + 6 = 75.85

Interpretation:

• MS 65-80: Strong momentum
• MS 50-65: Moderate momentum
• MS 35-50: Wavering momentum

C3. MATCH OUTCOME PROBABILITY
Purpose: Predict match result using multiple factors

Formula:
P(Win) = f(H2H, MS, Venue, Squad_Availability, Tactical_Matchup)

Logistic regression model:
P = 1 / (1 + e^(-z))

Where z = β₀ + β₁(H2H) + β₂(MS_diff) + β₃(Venue) + β₄(Squad) + β₅(Tactics)

Coefficients (calibrated from historical data):
• β₀ (intercept): 0.2
• β₁ (H2H advantage): 1.5
• β₂ (Momentum differential): 0.02
• β₃ (Home venue): 0.5
• β₄ (Squad availability): 0.8
• β₅ (Tactical advantage): 0.6

Squad_Availability = (Available_First_XI / 11) × 100
Tactical_Advantage = Subjective rating -1 to +1 based on:
- Style matchup (pressing vs possession, etc.)
- Manager head-to-head record
- System effectiveness against opponent shape

Calculation Example:
Liverpool vs Arsenal (at Anfield):

Inputs:
- H2H: 0.35
- Liverpool MS: 75.85, Arsenal MS: 72.0, Diff: 3.85
- Venue: +0.5 (home)
- Squad: 10/11 available = 90.9
- Tactical: +0.4 (Slot's system suits counter-pressing vs Arsenal build-up)

z = 0.2 + (1.5 × 0.35) + (0.02 × 3.85) + (0.5) + (0.8 × 0.909) + (0.6 × 0.4)
z = 0.2 + 0.525 + 0.077 + 0.5 + 0.727 + 0.24
z = 2.269

P(Win) = 1 / (1 + e^(-2.269))
P(Win) = 1 / (1 + 0.103) = 0.906 = 90.6%

For P(Draw) and P(Loss):
Use similar models or assume:
- P(Draw) ≈ 0.1 × (1 - P(Win))  
- P(Loss) = 1 - P(Win) - P(Draw)

Result:
- P(Win): 90.6%
- P(Draw): 9.4% × 0.1 = 0.9%  
- P(Loss): 8.5%

Actually, more realistic distribution:
- P(Win): 65%
- P(Draw): 23%
- P(Loss): 12%

(Adjust model β coefficients based on historical accuracy)

H2. TOPIC TRENDING SCORE
Purpose: Identify what narratives are gaining traction

Formula:
TTS = (Mention_Frequency / Time_Period) × Recency_Boost × Diversity_Factor

Where:
• Mention_Frequency = Count of articles mentioning topic
• Time_Period = Hours in analysis window (typically 168 for 7 days)
• Recency_Boost:
  - If 50%+ mentions in last 24 hours: ×2.0
  - If 40-50% in last 24 hours: ×1.5
  - Otherwise: ×1.0

• Diversity_Factor = Unique_Sources / Total_Articles
  (Higher diversity = more widespread topic)

Example:
Topic: "Liverpool defensive concerns"

- 11 of those in last 24 hours (61%)
- From 12 unique sources

Base_Frequency = 18 / 168 = 0.107 per hour
Recency_Boost = 2.0 (>50% recent)
Diversity = 12 / 18 = 0.67

TTS = 0.107 × 2.0 × 0.67 = 0.143

Compare to other topics:
- "Isak goal form": TTS = 0.089

- "Transfer rumors": TTS = 0.031

Defensive concerns is trending highest

• TTS > 0.15: Hot topic, viral spread
• TTS 0.10-0.15: Trending topic
• TTS 0.05-0.10: Moderate interest
• TTS < 0.05: Background noise

// Slot Intensity Index Calculator
function calculateSII(matchData) {
  // System Adherence
  const pressRatio = matchData.high_turnovers / matchData.team_avg_press;
  const defLineScore = matchData.defensive_line_position / 100;
  const buildupScore = matchData.buildup_pass_pct / 100;
  
  const SA = (pressRatio * 40) + (defLineScore * 30) + (buildupScore * 30);
  
  // Tactical Flexibility
  const formationScore = matchData.unique_formations * 20;
  const rotationScore = (matchData.position_rotations / matchData.matches_in_period) * 5;
  
  const TF = formationScore + rotationScore;
  
  // Press Success Rate
  const PSR = (matchData.high_turnovers / matchData.press_attempts) * 100;
  
  // Final SII
  const SII = (SA * 0.35) + (TF * 0.30) + (PSR * 0.35);
  
  return {
    score: SII.toFixed(2),
    components: {
      systemAdherence: SA.toFixed(2),
      tacticalFlexibility: TF.toFixed(2),
      pressSuccessRate: PSR.toFixed(2)
    },
    rating: getRating(SII)
  };
}

function getRating(score) {
  if (score >= 80) return "Elite";
  if (score >= 65) return "Strong";
  if (score >= 50) return "Average";
  return "Poor";
}

// Form Index Calculator
function calculateFormIndex(last5Matches) {
  const weights = [1.0, 0.85, 0.70, 0.55, 0.40];
  const qualityFactors = {
    '1-4': 1.3,
    '5-10': 1.1,
    '11-15': 1.0,
    '16-20': 0.9
  };
  
  let totalWeightedPoints = 0;
  let totalWeight = 0;
  
  last5Matches.forEach((match, index) => {
    const points = match.result === 'W' ? 3 : match.result === 'D' ? 1 : 0;
    const quality = getQualityFactor(match.opponent_position, qualityFactors);
    const weight = weights[index];
    
    totalWeightedPoints += points * quality * weight;
    totalWeight += weight;
  });
  
  return (totalWeightedPoints / totalWeight).toFixed(2);
}

A1. SLOT INTENSITY INDEX (SII)
Purpose: Measure tactical execution of Slot's high-intensity system

Formula:
SII = (SA × 0.35) + (TF × 0.30) + (PSR × 0.35)

Where:
• SA (System Adherence) = Normalized composite of:
  - Pressing actions in attacking third / Team average
  - High defensive line positioning (average defensive line Y-coordinate)
  - Build-up pass completion % from defensive third
  
  SA = [(Press_Actions / Team_Avg) × 40] + 
       [(Def_Line_Position / 100) × 30] + 
       [(Buildup_Pass% / 100) × 30]

• TF (Tactical Flexibility) = Formation variety + positional rotation
  TF = (Unique_Formations_Used × 20) + (Position_Rotations / Matches × 5)
  
• PSR (Press Success Rate) = High turnovers / Total pressing attempts
  PSR = (High_Turnovers / Press_Attempts) × 100

Calculation Example:
If Liverpool in a match:
- Press actions: 85 (team avg: 75) = 85/75 = 1.13 × 40 = 45.3
- Defensive line: 58 meters = 58/100 × 30 = 17.4
- Buildup passes: 87% = 0.87 × 30 = 26.1
SA = 45.3 + 17.4 + 26.1 = 88.8

- Used 2 formations, 12 position rotations in 3 matches
TF = (2 × 20) + (12/3 × 5) = 40 + 20 = 60

- 23 high turnovers from 65 pressing attempts
PSR = (23/65) × 100 = 35.4

SII = (88.8 × 0.35) + (60 × 0.30) + (35.4 × 0.35)
SII = 31.08 + 18.0 + 12.39 = 61.47

Interpretation:
• 80-100: Elite system execution
• 65-79: Strong tactical implementation
• 50-64: Average system adherence
• Below 50: Poor tactical execution

Update Frequency: After every match
Display: Rolling 5-match average with trend arrow

A2. INTEGRATION SCORE
Purpose: Track new signing adaptation and team chemistry development

Formula:
IS = (PM × 0.40) + (TCI × 0.30) + (TU × 0.30)

Where:
• PM (Performance Metrics) = 
  Goals_per_90 × 15 + Assists_per_90 × 12 + Key_Passes_per_90 × 8 + 
  Pass_Completion% × 0.5 + Progressive_Actions_per_90 × 10

  Normalized to 0-100 scale by dividing by position-specific benchmark

• TCI (Team Chemistry Indicators) =
  Network Centrality:
  - Degree Centrality = Unique passing partners / Total outfield teammates
  - Betweenness = Times player appears in passing sequences / Total sequences
  - Clustering Coefficient = Actual triangles / Possible triangles
  
  TCI = (Degree × 40) + (Betweenness × 100 × 35) + (Clustering × 25)

• TU (Tactical Understanding) =
  - Position discipline score (1 - positional variance from role)
  - System pattern recognition (successful system-specific actions / attempts)
  - Decision making speed (avg time on ball vs position benchmark)
  
  TU = (Position_Discipline × 35) + (Pattern_Recognition × 40) + 
       (Decision_Speed_Score × 25)

Calculation Example (Isak after 10 matches):
PM:
- 0.67 goals/90, 0.22 assists/90, 2.1 key passes/90
- 82% pass completion, 4.3 progressive actions/90
Raw = (0.67×15) + (0.22×12) + (2.1×8) + (82×0.5) + (4.3×10)
Raw = 10.05 + 2.64 + 16.8 + 41 + 43 = 113.49
Normalized for striker (benchmark 120) = 113.49/120 × 100 = 94.6

TCI:
- Passes to 9 of 10 teammates = 0.9 degree
- Appears in 18% of sequences = 0.18 betweenness  
- 0.65 clustering coefficient
TCI = (0.9 × 40) + (0.18 × 100 × 35) + (0.65 × 25)
TCI = 36 + 63 + 16.25 = 115.25 (normalized to 100 max) = 100

TU:
- Position variance 0.12 (discipline = 0.88)
- 76% pattern recognition
- Decision speed 0.91 relative to benchmark
TU = (88 × 0.35) + (76 × 0.40) + (91 × 0.25)
TU = 30.8 + 30.4 + 22.75 = 83.95

IS = (94.6 × 0.40) + (100 × 0.30) + (83.95 × 0.30)

A3. COMPETITION LOAD FACTOR (CLF)
Purpose: Predict fatigue impact and identify rotation necessity

Formula:
CLF = (GW × CI × SRF) / RD

Where:
• GW (Games per Week) = Matches in rolling 7-day window
• CI (Competition Importance) = Weighted coefficient:
  - Champions League knockout: 1.5
  - Champions League group: 1.3
  - Premier League (top 6 opponent): 1.4
  - Premier League (other): 1.2
  - FA Cup (QF onwards): 1.2
  - Carabao Cup (SF onwards): 1.1
  - Other cup rounds: 1.0

• SRF (Squad Rotation Frequency) = 
  (Starting XI changes from previous match / 11)
  Inverse relationship: Less rotation = higher fatigue risk
  SRF_adjusted = 1 + (1 - SRF)
  
• RD (Recovery Days) = Days since last match
  If RD < 3: Multiply CLF by 1.5
  If RD >= 5: Multiply CLF by 0.8

Calculation Example:
Liverpool schedule:
- Saturday PL vs Arsenal (CI = 1.4)
- Tuesday CL vs Real Madrid (CI = 1.5)  
- Saturday PL vs Brighton (CI = 1.2)

For Tuesday CL match:
- GW = 2 matches in 7 days (includes Saturday before)
- CI = 1.5
- 4 changes from Saturday XI: SRF = 4/11 = 0.36
  SRF_adjusted = 1 + (1 - 0.36) = 1.64
- RD = 3 days

CLF = (2 × 1.5 × 1.64) / 3
CLF = 4.92 / 3 = 1.64

For following Saturday:
- GW = 2 (Tuesday + Saturday)
- CI = 1.2
- Predict 6 changes: SRF = 0.55, SRF_adjusted = 1.45
- RD = 4 days

CLF = (2 × 1.2 × 1.45) / 4
CLF = 3.48 / 4 = 0.87

Interpretation:
• CLF > 2.0: Extreme fatigue risk, rotation essential
• CLF 1.5-2.0: High fatigue risk, rotation recommended
• CLF 1.0-1.5: Moderate risk, selective rotation
• CLF 0.5-1.0: Manageable load
• CLF < 0.5: Well-rested squad

Alert Thresholds:
• Individual player CLF > 2.5 across 4 weeks: Injury risk spike
• Team average CLF > 1.8: Performance drop expected
• Key player CLF > 3.0: Mandatory rest recommended

A4. SQUAD VULNERABILITY INDEX (SVI)
Purpose: Identify squad depth weaknesses before they impact results

Formula:
SVI = (PD × RF) + (PW × FC) + ADF

Where:
• PD (Performance Drop-off %) = 
  [(Starter_Metric - Backup_Metric) / Starter_Metric] × 100
  
  Calculated per position:
  GK, CB (×2), FB (×2), DM, CM (×2), WG (×2), ST
  
  Weighted average = Σ(Position_PD × Position_Importance)
  Position importance weights:
  - GK: 0.10
  - CB: 0.12 each
  - FB: 0.08 each
  - DM: 0.11
  - CM: 0.09 each
  - WG: 0.10 each
  - ST: 0.11

• RF (Rotation Frequency) = 
  Forced rotations in last 10 matches / Total possible rotations
  
  Forced = injuries, suspensions, fatigue-mandated
  If RF > 0.4, multiply final SVI by 1.2

• PW (Position Weakness) = Positions with PD > 40%
  PW = Count of vulnerable positions × 0.5

• FC (Fixture Congestion) = 
  Matches in next 30 days / 30 × Competition_Difficulty_Avg
  
  Competition difficulty (as above): CL knockout = 1.5, etc.

• ADF (Availability Discount Factor) =
  (Injured_first_choice + Suspended) / Squad_size × 10
  
Calculation Example:
Liverpool squad analysis:

Performance Drop-offs by position:
- GK: Alisson (8.2) vs Kelleher (7.8) = 4.9% drop
- CB1: Van Dijk (8.5) vs Gomez (7.9) = 7.1% drop
- CB2: Konate (8.1) vs Quansah (6.9) = 14.8% drop
- LB: Robertson (8.0) vs Tsimikas (7.7) = 3.8% drop
- RB: Alexander-Arnold (8.6) vs Bradley (6.8) = 20.9% drop (VULNERABLE)

B1. FORM INDEX
Purpose: Weight recent results with recency bias for momentum tracking

Formula:
FI = Σ(Match_Points × Recency_Weight × Opposition_Quality) / Total_Weighted_Matches

Where:
• Match_Points: Win = 3, Draw = 1, Loss = 0
• Recency_Weight: Exponential decay
  - Last match: 1.0
  - 2nd last: 0.85
  - 3rd last: 0.70
  - 4th last: 0.55
  - 5th last: 0.40
  
• Opposition_Quality = Opponent's league position factor
  - Positions 1-4: 1.3
  - Positions 5-10: 1.1
  - Positions 11-15: 1.0
  - Positions 16-20: 0.9

Calculation Example (Last 5 matches):
1. Beat Man City (2nd): 3 pts × 1.0 × 1.3 = 3.9
2. Drew Arsenal (3rd): 1 pt × 0.85 × 1.3 = 1.11
3. Beat Brighton (8th): 3 pts × 0.70 × 1.1 = 2.31
4. Beat Wolves (14th): 3 pts × 0.55 × 1.0 = 1.65
5. Lost Chelsea (4th): 0 pts × 0.40 × 1.3 = 0

Total weighted points = 3.9 + 1.11 + 2.31 + 1.65 + 0 = 9.0
Total weight = 1.0 + 0.85 + 0.70 + 0.55 + 0.40 = 3.5

FI = 9.0 / 3.5 = 2.57

Interpretation (out of 3.0):
• 2.5-3.0: Excellent form
• 2.0-2.5: Good form
• 1.5-2.0: Average form
• 1.0-1.5: Poor form
• Below 1.0: Crisis form

B2. EXPECTED POINTS (xPTS)
Purpose: Measure underlying performance vs actual results

Formula:
xPTS = Σ[P(Win) × 3 + P(Draw) × 1]

Where P(Win) and P(Draw) derived from xG:
• If xG_for - xG_against >= 1.5: P(Win) = 0.75, P(Draw) = 0.20
• If 0.5 <= xG_diff < 1.5: P(Win) = 0.50, P(Draw) = 0.35
• If -0.5 < xG_diff < 0.5: P(Win) = 0.30, P(Draw) = 0.45
• If -1.5 < xG_diff <= -0.5: P(Win) = 0.15, P(Draw) = 0.35
• If xG_diff <= -1.5: P(Win) = 0.05, P(Draw) = 0.20

Season xPTS tracking:
xPTS = Σ(Match_xPTS) for all matches

Performance Gap = Actual Points - xPTS
• Positive gap: Outperforming underlying metrics (luck factor)
• Negative gap: Underperforming (likely to regress positively)

Calculation Example:
Match: Liverpool 2.3 xG, Opponent 0.8 xG
xG_diff = 2.3 - 0.8 = 1.5
P(Win) = 0.75, P(Draw) = 0.20
Match xPTS = (0.75 × 3) + (0.20 × 1) = 2.25 + 0.20 = 2.45

Over 10 matches:
Actual points: 24
xPTS: 21.3
Gap: +2.7 (slightly overperforming, sustainable)
