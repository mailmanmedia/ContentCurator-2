# Replit Production Studio Research: OBS-Style Web Application Guide

## Main Findings

Building an OBS-style production studio in Replit is **technically feasible** with specific architectural considerations. The key is leveraging Replit's Node.js capabilities while working within its resource constraints and providing explicit instructions to AI agents.

## Core Technical Stack

**Frontend Architecture**: HTML5 Canvas with drag-and-drop overlay editor, CSS3 animations, and WebSocket real-time communication[1][2][3]

**Backend Infrastructure**: Node.js/Express server with WebSocket support, RSS parsing via rss-parser library, and static asset management[4][5][6]

**OBS Integration**: Standard web technologies work directly in OBS Browser Sources, supporting custom CSS injection and JavaScript events through `window.obsstudio`[7][8][9]

## Critical Implementation Requirements

### 1. **Dynamic Overlay System**
- HTML5 Canvas-based editor with native drag-and-drop API[2][1]
- Liverpool FC branded templates with official colors (#C8102E, #00B2A9, #F6EB61)
- Real-time preview system with WebSocket updates[10][5]
- Template-based approach for match scenarios (pre-match, live, post-match)

### 2. **RSS Feed Integration**
- Multi-source aggregation from Liverpool FC official feeds, BBC Sport, Sky Sports[11][12]
- Real-time news banner system with scrolling ticker implementation[13][14]
- Automatic content filtering and Liverpool FC relevance scoring
- Fallback systems for RSS feed failures with backup sources[15]

### 3. **Replit-Specific Considerations**
- **Resource limitations**: Maximum 20 concurrent Repls, CPU/RAM constraints on free tiers[16][17]
- **Explicit file structure**: Agent needs clear directory organization and environment variable setup
- **Error handling**: Robust timeout systems for external RSS feeds and WebSocket connections
- **Performance optimization**: Canvas rendering with requestAnimationFrame, image caching, RSS polling limits

## Key Agent Instructions

1. **File Structure**: Create organized directories for overlays, assets, server components, and configuration files
2. **Environment Setup**: Define RSS feed URLs, WebSocket ports, and Liverpool FC branding assets
3. **Error Handling**: Implement timeout systems for RSS feeds (10-second limit) and WebSocket reconnection logic
4. **Performance**: Use efficient canvas rendering, image caching, and minimize RSS polling frequency
5. **OBS Compatibility**: Ensure all overlays work as Browser Sources with proper HTTPS and CORS configuration

The production studio will enable easy overlay editing through drag-and-drop interfaces, real-time RSS news integration, and Liverpool FC branded templates—all optimized for Replit's environment and OBS Browser Source compatibility.
